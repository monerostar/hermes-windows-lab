# Profiles: main vs tech

Hermes profiles are separate working homes (config, skills, sessions, memory).

Rough split used here:

| Profile | Role |
|---------|------|
| **main** | Gateway / light chat / life routing |
| **tech** | Hands-on computer work, deeper tooling |

Implications:

- Skills and MCP can differ per profile
- Confirm which profile is active before changing models, keys, or integrations
- Cross-profile skill sharing needs an intentional mount/copy strategy — do not assume everything is global

Desktop tech sessions typically use the tech profile `HERMES_HOME`.
