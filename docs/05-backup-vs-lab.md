| | **hermes-backup** (private) | **hermes-windows-lab** (this repo) |
|--|-----------------------------|-------------------------------------|
| Job | Disaster recovery | Learning + portfolio-shaped docs |
| Contents | Profile snapshots, skills dump, zips | Scrubbed notes, samples, scripts |
| Audience | Future you restoring a machine | Future you (and maybe public later) |
| Update cadence | After meaningful setup changes | When you learn or document something |
| Secrets | Must stay private; still scrub if possible | Must not contain secrets |
